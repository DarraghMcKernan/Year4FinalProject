# Year 4 Final Year Project
## Description
### This is a brief synopsis, more detailed descriptions and explanation can be found in the documentation found in the repo uner the titles: GDD-C00271651.docx, TDD-C00271651.docx and ProjectReport-C00271651.docx.
### The GDD (Game Design Document) is an ovewrview on what the game will do and what features will be like, The TDD (Technical Design Document) gives details on how the features work with descriptions and explanations of major parts of the codebase. The project report is a retrospective look at the project including progress, achievements, changes and additions over time and also things that I would have done differently.
### This project was made over the span of my final year in college and is built in c++ using SFML for the graphics. The game was designed to be as modular and dynamic as possible with the vast majority of the game being easily changed by just modifying a few variables. The game features a grid based world that the units can navigate and a custom world editor to allow the user to modify and create their own version of the level and is how I created the level originally. The units also highly modifiable and can be easily modified, the player can also create their own custom unit from inside the game using the menus provided. A major component of the game is how the units navigate the world, if multiple units are selected they will be added to a formation and will do their best to stay in the formation. If they are not able to get to their designated position they will swap between several different unique behaviours in order to get to where they need to be. Another major feature is the way in which textures are set when the world is created or modified. If a tile is changed it will automatically check its neighbouring tiles to see what type of tiles they are and set its own texture accordingly so that the user does not have to worry about placing in specific textures or tiles, the use simply gets to draw on the map where they would like obstacles and the game handles the rest.
